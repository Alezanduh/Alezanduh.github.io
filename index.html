featured projects

Insights For Michigan Men's Basketball

Partnered with SkillCorner to engineer spatial and spacing features from high-frequency computer-vision tracking data, then built XGBoost models of Shot Quality and EPA to evaluate pick-and-roll decisions for the coaching staff. Presented at the organization's annual symposium.

GitHub ↗ Presentation ↗

NBA Interactive Dashboard

End-to-end web app that ingests live play-by-play data through the nba_api and generates matchup summaries from 2005 to present. Models real-time momentum shifts with time-decayed algorithms and a reactive Streamlit front end.

Dashboard ↗ GitHub ↗

Wayne County Legal Justice Analysis

Python pipeline that parses and standardizes 31,000 Wayne County case files (2000–2025) into structured JSON and a SQLite database, then analyzes weapons felony charges against Michigan Compiled Laws (MCL) to surface potential over-prosecution and charging stacking that contribute to plea-bargaining disparities.

GitHub ↗ Initial Findings ↗

Deep Neural Network For NBA Player Forecasting

Deep neural network using Pytorch and TensorFlow trained on rolling seasons to forecast NBA player performance, with normalization and one-hot encoding of positional features, K-fold cross-validation, and regularization to reduce overfitting.

GitHub ↗
